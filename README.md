# Soma Clothing – Fashion E-commerce Frontend

A responsive and interactive e-commerce frontend application built with **React.js** and **Tailwind CSS**, showcasing a modern shopping experience for fashion products like polos, jeans, and shirts.

## 🔎 Live Demo

[Live Site](https://somaclothing.vercel.app)

## 🔑 Features

* 🛒 **Shopping Cart** with size and quantity selection, subtotal, and total calculation
* 📦 **Dynamic Product Pages** with image thumbnails and product details
* 🛍️ **Filtering & Sorting** options (category, price)
* ⚖️ **React Context API** for centralized cart state management
* ⚠️ **Toast Alerts** for user feedback and validation (e.g., missing size)
* 💻 Fully **Responsive Design** for mobile, tablet, and desktop

## 🛠️ Tech Stack

* React.js
* Tailwind CSS
* React Router
* React Toastify
* Context API (for state management)

## ✨ Getting Started

1. Clone the repository:

```bash
git clone https://github.com/muneebimtiazz/soma-clothing.git
cd soma-clothing
```

2. Install dependencies:

```bash
npm install
```

3. Start development server:

```bash
npm run dev
```

## 💼 Folder Structure

```
src/
├── assets/           # Images & product data
├── components/       # Reusable components (e.g., Navbar, Footer, ProductCard)
├── context/          # Context API for cart state
├── pages/            # Main pages (Home, Shop, Cart, etc.)
└── App.jsx           # Entry point with routes
```
